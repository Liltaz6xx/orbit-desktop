# ORBIT Desktop 0.7.0 beta 11

The desktop workspace has a refreshed toolbar, clearer subtitles and direct access to **History** and **Macros**.

**History** searches and displays saved exchanges already on the PC. You can copy an exchange or clear conversation history while keeping saved facts.

**Macros** records Windows keyboard and mouse input. Choose **New recording**, switch to the app during the countdown, perform your steps and press **F8** to stop. Name and save the recording, then select it and choose **Replay**. Focus the target app during the countdown and keep its window and display arrangement the same. Recordings include typed keys, so leave passwords out.

If your installed build already has an **Update** button, use it to install this release. Otherwise download and run Windows Setup.

Open **Settings** to change the assistant name, choose from seven Kokoro voices and four personalities, or enable the microphone. With an English Windows Speech recognizer installed, say **Hey ORBIT** (or use your chosen name), wait for the listening indicator, then say your request. Recognition runs on your PC while the assistant is idle.

Existing command routines remain in **Settings** and run with commands such as **run macro work**.

Download and run the **Windows x64 Setup EXE**. Setup installs Python and its dependencies, Ollama, Qwen2.5 1.5B, and the Kokoro voice as needed. A clean installation downloads about 3 GB. Open ORBIT from the Start menu or the desktop shortcut selected by default.

Run the EXE to update an installed copy. Setup reuses verified dependencies and preserves saved memories, settings and existing model files. To retry an interrupted dependency download, run Setup again.

ORBIT automatically advertises **Playing ORBIT** while the Discord desktop app is running. The **Discord** button shows its connection status. Visibility follows Discord's activity-sharing settings. Conversations and saved memories stay local.

The installer is unsigned. The attached SHA-256 file lets you verify the download. The source ZIP is also available for manual installs.
